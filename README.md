# Kaitos

Веб-редактор файлов в браузере с поддержкой Git, Docker и локального LLM (Ollama). Работает без привязки к конкретному серверу.

## Кратко о возможностях

- **Файловая система**: доступ ко всем файлам на ПК через `browser://`, навигация по папкам, чтение/редактирование, Git для версионности истории изменений.
- **Локальная нейросеть**: Ollama подхватывается автоматически при первом запросе к модели; работает и без неё (как обычный редактор).
- **Docker/Podman/Fuse**: монтирование Docker-образов из `data/`, поддержка Podman в качестве альтернативы.
- **Git integration**: коммит, бранчинг прямо через интерфейс, интеграция с GitHub/GitLab за счёт API и HTTPS (включая SSH если настроено).

## Quick start — запустить сервер

### Вариант 1: один клик для всех файлов + GUI (`start.bat`) — Windows
**Двойной щелчок по `start.bat` в корне проекта.**  
Что происходит при старте, описано ниже. Если двойного клика на Windows нет, используйте «Запуск» через терминал (пункт 2).

### Вариант 2: ручной старт сервера + GUI
1) В PowerShell / Terminal командой без прав elevated:
    ```powershell
    npm run dev:full
    ```
   Это запустит Node.js и откроет браузер на `http://localhost:5173` с приложением, а также локальный Docker-сервер (если доступен).

### Как остановка?

**Windows:** нажмите Ctrl+C в том же окне терминала где вы запустили сервер; если это был двойной клик по `start.bat`, то окно само закроется после завершения процессов.

## Запуск через терминал — полное приложение (+ Docker-сервер)

1. В PowerShell / Terminal (не elevated):
    ```powershell
    npm run dev:full
    $$env:PATH contains node_modules\.bin && [Console]::TreatControlCAsInput = $true; [System.AppDomain] CurrentDomain.StartMethodInfo -invoke 2>&1 | Out-Null; Start-Sleep -Seconds 50
    ```

Но проще — используйте `start.bat` и пункт выше.

## Настройка Git/SSH (если нужно)

Если используете Git, а SSH не настроен: настройте ключи через `ssh-agent` / OpenSSH или замените протокол на HTTPS в репозиториях проекта. Для монтирования Docker-образов укажите путь к их директории (см. секцию «Docker» ниже).

## Тестирование/разработка

Проект использует [Vite](https://vitejs.dev/) для разработки и продакшена; сборка в `dist/`. Команды:
- Разработка: `npm run dev` — только приложение (режим SPA, без Docker/Podman).
- Продакшен сборка: `npm run build`, затем сервер из `server/index.js`.

## Ограничения и известные проблемы

Приложение поддерживает современные браузеры с ES Modules; старые Chrome/Firefox могут не работать. Для Git-монтирования убедитесь, что репозиторий доступен по SSH/HTTPS (или используйте `git://`). Docker/Podman обязательны для доступа к образовам в контейнерах проекта.

## Troubleshooting — частые ошибки запуска

Если команда ниже говорит «command not found», то Node.js не установлен:
    ```bash
    npm run dev:full
    ```
Вместо этого установите Nodejs с https://nodejs.org/ и следуйте руководству по ссылке выше. Ключевая ошибка при старте проекта — отсутствие `node` в пути пользователя; исправляется установкой через официальный installer или package-менеджер ОС (choco/scoop/winget).

Если после установки зависимости есть конфликт версий, используйте:
    ```bash
    npm ci --force && npm audit fix
    ```

## Лицензия и авторство

Проект создан в рамках обучения работе с Node.js + Vite. Включает файловую систему (file://), Git-интеграцию, Docker/Podman поддержку и LLM через Ollama как демонстрационный стек для браузерных приложений.
