# Kaitos

AI-редактор кода в браузере — аналог Cursor / Claude Code: дерево файлов, редактор с вкладками,
чат с ассистентом, встроенный терминал, палитра команд и настройки модели.

## Запуск

```bash
npm install
npm run dev:full # сервер файлов (5178) + приложение (5173) — работа с настоящими файлами
npm run dev      # только приложение: демо-режим, файлы в памяти браузера
npm run server   # только сервер файлов
npm test         # 90 сквозных проверок (jsdom + node)
npm run test:live # проверка против запущенного сервера (нужны server и dev)
npm run build    # сборка в dist/
```

Если приложение открыто за https-прокси và нужен HMR: `KAITOS_HMR_WSS=1 npm run dev`.

## Возможности

- **Настоящие файлы на диске** через локальный сервер (`npm run server`), с демо-режимом как запасным
- Панель файлов, редактор с вкладками, нумерацией строк и **подсветкой синтаксиса** (js, css, html, json, md, sh), `Ctrl+S`
- **Ассистент с настоящей моделью:** Ollama локально или любой OpenAI-совместимый API,
  потоковые ответы, «Остановить», markdown с копированием кода
- Контекст запроса: открытый файл (до 12 000 символов) и история диалога
- **Правки от ассистента:** модель предлагает новое содержимое файла, приложение показывает diff
  с кнопками «Применить» / «Отклонить»; опасные пути блокируются
- Встроенный терминал, палитра команд `Ctrl+K`, тёмная и светлая темы
- Настройки: провайдер, модель, ключ, температура, длина ответа, «Проверить соединение»

## Подключить модель

1. **Ollama (локально, без интернета):** установите Ollama, выполните `ollama pull qwen3.5:9b`,
   запустите с `OLLAMA_ORIGINS=*` (иначе браузер не сможет к ней обратиться).
2. В приложении: «Настройки» → провайдер «Ollama» → модель `qwen3.5:9b` → «Проверить соединение» → «Сохранить».
3. **Или внешний API:** провайдер «OpenAI-совместимый», адрес, модель, ключ. Ключ хранится только в вашем браузере.

## Стек

- Vite 5 (сборка и dev-сервер), без фреймворков
- Чистый ES-модульный JavaScript (`js/*.js`)
- CSS-переменные, тёмная и светлая темы (`css/style.css`)

## Структура

```
index.html          разметка всего экрана (панели, вкладки, чат, терминал, модалки)
css/style.css       дизайн-система и вёрстка
js/app.js           точка входа: собирает модули, связывает их между собой
js/dom.js           помощники для DOM
js/fs.js            виртуальная файловая система (демо-проект в памяти)
js/editor.js        редактор кода: вкладки, нумерация строк, сохранение
js/tree.js          дерево файлов в левой панели
js/chat.js          панель ассистента (пока демо-ответы)
js/terminal.js      встроенный терминал (виртуальные команды)
js/settings.js      настройки: провайдер, модель, ключ, тема, шрифт
js/palette.js       палитра команд (Ctrl+K)
js/llm.js           клиент моделей (Ollama, OpenAI-совместимые API), поток и отмена
js/prompts.js       системный промпт и сборка контекста
js/markdown.js      разметка ответов ассистента
js/tools.js         разбор правок файлов из ответа модели
js/diff.js          построчный diff для предпросмотра правок
js/highlight.js     подсветка синтаксиса без зависимостей
js/api.js           клиент локального сервера файлов
js/fs-remote.js    _files_ с диска (зеркало в памяти + запись в фоне)
server/paths.js     защита путей: только внутри проекта
server/files.js     чтение, запись, список файлов через node:fs
server/index.js     HTTP API сервера файлы
tests/e2e/*.yml     постоянные сценарии проверки интерфейса
tests/*.mjs         сквозные тесты (npm test)
```

## Дорожная карта

1. **Каркас** — готово: экран, дерево файлов, редактор, чат, терминал, настройки, палитра.
2. **Нейросеть** — готово: Ollama и OpenAI-совместимые API, потоковые ответы, контекст файла.
3. **Инструменты агента** — готово: правки файлов с предпросмотром diff и защитой путей.
4. **Подсветка синтаксиса** — готово: свой токенизатор и слой под `textarea`.
5. **Локальный сервер** — готово: настоящие файлы на диске, API с защитой путей.
6. **Git-панельи запуск команд** — далее.
