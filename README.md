# Kaitos

AI-редактор кода в браузере — аналог Cursor / Claude Code: дерево файлов, редактор с вкладками,
чат с ассистентом, встроенный терминал, палитра команд и настройки модели.

## Запуск

```bash
npm install
npm run dev
```

Приложение откроется на http://localhost:5173

## Стек

- Vite 5 (сборка и dev-сервер), без фреймворков
- Чистый ES-модульный JavaScript (`js/*.js`)
- CSS-переменные, тёмная и светлая темы (`css/style.css`)

## Структура

```
index.html          разметка всего экрана (панели, вкладки, чат, терминал, модалки)
css/style.css       дизайн-система и вёрстка
js/app.js           точка входа: собирает модули, связывает их между собой
js/dom.js           помощники для DOM
js/fs.js            виртуальная файловая система (демо-проект в памяти)
js/editor.js        редактор кода: вкладки, нумерация строк, сохранение
js/tree.js          дерево файлов в левой панели
js/chat.js          панель ассистента (пока демо-ответы)
js/terminal.js      встроенный терминал (виртуальные команды)
js/settings.js      настройки: провайдер, модель, ключ, тема, шрифт
js/palette.js       палитра команд (Ctrl+K)
tests/e2e/*.yml     постоянные сценарии проверки интерфейса
```

## Дорожная карта

1. **Каркас** (сейчас): экран, дерево файлов, редактор, чат, терминал, настройки, палитра.
2. **Нейросеть**: подключение Ollama и OpenAI-совместимых API, потоковые ответы.
3. **Инструменты агента**: чтение/запись файлов, правки diff-ом, команды терминала.
4. **Локальный сервер**: доступ к настоящим файлам на диске, git-панель.
