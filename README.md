# Kaitos

AI-редактор кода в браузере — аналог Cursor / Claude Code: дерево файлов, редактор с вкладками,
чат с ассистентом, встроенный терминал, палитра команд и настройки модели.

## Запуск

**Windows:** двойным щелчком откроете `start.bat` (в корневой папке). При первом запуске установятся зависимости через `npm ci`, затем приложение запустится в браузере на http://localhost:5173, а сервер файлов — на 5178. Остановите правкой терминала по Ctrl+C и удалением процессов.

```bash
start.bat           # Windows быстрое начало (все сервисы)
npm i               # если нет package-lock.json или для ручной установки deps
node scripts/dev-all.mjs   # альтернативный скрипт запуска всего проекта без GUI окна Node
npm run dev:full    # сервер файлов (5178) + приложение (5173) — работа с настоящими файлами
npm run dev         # только приложение: демо-режим, файлы в памяти браузера
npm run server      # только сервер файлов
npm test            # 164 сквозных проверок (jsdom + node), зависимости поставятся сами
npm run test:live   # проверка против запущенного сервера (нужны server и dev)
npm run build       # сборка в dist/
```

Если приложение открыто за https-прокси и нужен HMR: `KAITOS_HMR_WSS=1 npm run dev`.
