# Запуск

## Одна команда

```bash
npm run dev:full
```

Поднимает два процесса: сервер файлов (`127.0.0.1:5178`) и приложение Vite (`localhost:5173`).

## Что должно быть в выводе

```
Kaitos server: http://127.0.0.1:5178
Проект:       <папка проекта>
VITE v5 ready
```

Если строки `Kaitos server:` нет — сервер не стартовал. Смотрите ошибку выше: чаще всего это занятый порт.

## Проверка

```bash
curl http://localhost:5173/api/health
```

Ответ: JSON с полями `ok`, `root`, `files`. После этого в приложении внизу написано «диск: <папка>».
