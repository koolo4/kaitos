# Если что-то не работает

## Приложение показывает «демо (в памяти)»

Значит браузер не достучался до локального сервера файлов.

1. Запустите сервер: `npm run server` (порт 5178).
2. Или сразу оба процесса: `npm run dev:full`.
3. Проверьте связь: откройте `http://localhost:5173/api/health` — должен быть JSON с полем `root`.
4. Если задан `KAITOS_TOKEN`, тот же токен нужен в настройках приложения.
5. `npm run server` должен напечатать строку `Kaitos server: http://127.0.0.1:5178`. Если вывода нет —
   сервер не стартовал, смотрите ошибку в консоли.
6. Если порт занят, сервер скажет об этом прямо. Другой порт: `KAITOS_PORT=5179 npm run server`
   (тогда и приложению нужен адрес: `KAITOS_API=http://127.0.0.1:5179 npm run dev`).

## Работает, но медленно

- При старте приложение читает все файлы проекта в память. Большой проект — долгий старт.
- Слежение за файлами опрашивает сервер раз в 1.5 секунды.

## Терминал пишет «команда не выполнилась»

- Без локального сервера терминал работает в демо-режиме: доступны только виртуальные команды.
- Команда ограничена 60 секундами и 200 КБ вывода.

## Git-панель пустая

- Панель работает только в режиме диска и только если папка проекта — git-репозиторий.
- Если в папке нет git, панель честно пишет «проект не под git».

## Правка от ассистента не применяется

- Формат «найти и заменить» требует, чтобы фрагмент встречался в файле ровно один раз.
- Если фрагмент не найден, добавьте в «НАЙТИ» соседние строки из файла.
