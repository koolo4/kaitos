# Локальный сервер файлов

Без сервера Kaitos работает в демо-режиме: файлы живут в памяти браузера и пропадают
после перезагрузки. С сервером приложение читает и пишет настоящие файлы проекта на диске.

## Запуск

```bash
npm run server     # http://127.0.0.1:5178, папка запуска = корень проекта
npm run dev        # http://localhost:5173, Vite проксирует /api на 5178
```

Обе команды сразу: `npm run dev:full`.

## Настройки

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `KAITOS_PORT` | `5178` | порт сервера |
| `KAITOS_HOST` | `127.0.0.1` | адрес; наружу сервер не смотрит |
| `KAITOS_ROOT` | текущая папка | корень проекта |
| `KAITOS_TOKEN` | пусто | если задан, нужен заголовок `X-Kaitos-Token` |

## API

| Метод и путь | Что делает |
|---|---|
| `GET /api/health` | проверка связи: корень и число файлов |
| `GET /api/files` | список файлов проекта |
| `GET /api/file?path=…` | содержимое файла |
| `POST /api/file` | записать файл: `{"path": "…", "content": "…"}` |
| `DELETE /api/file?path=…` | удалить файл |

## Безопасность

- Все пути приводятся к абсолютным и проверяются: выйти за пределы проекта нельзя.
- Папки `.git`, `.justai` и `node_modules` недоступны.
- Файлы больше 2 МБ и двоичные файлы не читаются.
- Сервер слушает только `127.0.0.1`.
