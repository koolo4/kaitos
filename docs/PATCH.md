# Точечные правки

Ассистент может предложить правку двумя способами.

## Найти и заменить

Подходит для небольших изменений: модель присылает только фрагмент, который надо заменить.

```
```kaitos-edit src/utils.js
<<<<<<< НАЙТИ
return `Привет, ${name}!`;
=======
return `Здравствуй, ${name}!`;
>>>>>>> ЗАМЕНИТЬ
```
```

Правила:

- Фрагмент «НАЙТИ» должен встречаться в файле ровно один раз, иначе правка отклоняется с подсказкой.
- Разница в переводах строк и хвостовых пробелах прощается.
- Если фрагмент не найден — правка не применяется и объясняет причину.

## Полное содержимое

Блок `kaitos-write` присылает файл целиком. Он нужен для новых файлов и полной перезаписи,
но для одной строки его лучше не использовать: модель может задеть соседние строки.

## Подтверждение

Любая правка сначала показывается как diff с кнопками «Применить» и «Отклонить».
