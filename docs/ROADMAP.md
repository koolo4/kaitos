# Что дальше

Готово: дерево файлов, редактор с подсветкой, ассистент, правки с diff, локальный сервер,
слежение за файлами, git-панель, команды в терминале, точечные правки.

## Ближайшие шаги

Готово: уведомление о конфликте, если файл изменился на диске, пока в редакторе есть несохранённый черновик.
Черновик сохраняется, внешняя версия не перезаписывает его; предупреждение показывается в интерфейсе
и терминале.

Готово: команду в терминале можно остановить кнопкой «Остановить». Отмена доходит до сервера и
завершает процесс вместе с дочерними процессами, а не только закрывает запрос.

Готово: переключение между локальными ветками в Git-панели. Оно запрещено при несохранённых
черновиках редактора или грязной рабочей копии; после перехода файловое зеркало перечитывается.

Готово: перед переключением Git-панель сравнивает выбранную локальную ветку с текущей и показывает
изменённые, добавленные, удалённые и переименованные файлы. Переключение недоступно, пока сравнение
не завершено успешно.

Готово: журнал коммитов отображается в Git-панели — хеш, сообщение, автор и относительное время.

Готово: чатовый режим «План» сначала показывает шаги и список файлов, затем после подтверждения применяет правки только по согласованным путям.

Готово (MVP): проектная память и backlog — цели и задачи сохраняются в браузере, ИИ предлагает backlog на подтверждение, зависимости блокируют преждевременный запуск задачи. Скрипты test/build/lint/check из package.json можно выполнить только после явного подтверждения; результат сохраняется, а ошибку можно передать агенту для плана исправления.

Дальше: цикл исправления с повторной проверкой, расширение на другие типы проектов и межбраузерная память только по явному согласию.
