# Что дальше

Готово: дерево файлов, редактор с подсветкой, ассистент, правки с diff, локальный сервер,
слежение за файлами, git-панель, команды в терминале, точечные правки.

## Ближайшие шаги

1. Уведомление о конфликте: файл изменён и на диске, и в редакторе.
2. Остановка команды из терминала.
3. Переключение ветвей и журнал коммитов в панели git.
4. Просмотр журнала коммитов прямо в панели (API уже есть).
