# Ограничения

- Сервер смотрит только на `127.0.0.1` и работает в папке, из которой запущен.
- Один файл — не больше 2 МБ; двоичные файлы не читаются.
- Список файлов ограничен 5000 записями, глубина обхода — 24 уровня.
- Команда в терминале ограничена 60 секундами и 200 КБ вывода; интерактивные программы не поддерживаются.
- Слежение за файлами опрашивает сервер раз в 1.5 секунды.
- Коммит из git-панели делает `git add -A`, то есть забирает все изменения проекта.
- Точечная правка требует единственного совпадения фрагмента в файле.
