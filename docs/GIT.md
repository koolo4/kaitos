# Git-панель

Панель находится под списком файлов. Она показывает ветку, число изменений и сами изменённые файлы.

## Что видно

| Значок | Значение |
|---|---|
| M | файл изменён |
| A | файл добавлен в индекс |
| D | файл удалён |
| R | файл переименован |
| ? | новый файл, ещё не под git |

## Что можно сделать

1. Кликнуть по файлу — откроется diff с подсветкой добавленных и удалённых строк.
2. Нажать «Журнал» — покажутся последние 20 коммитов: хеш, сообщение, автор и относительная дата.
3. Выбрать локальную ветку и нажать «Перейти».
4. Написать сообщение коммита и нажать «Закоммитить» (или `Ctrl+Enter`).

Переключение ветки запрещено, если есть несохранённые правки в редакторе или изменения в рабочей копии.
Сначала сохраните или закоммитьте файлы. После переключения дерево и открытые вкладки перечитываются с диска.

Коммит делает `git add -A`, то есть забирает все изменения проекта целиком.

## Если git не настроен

- В обычной папке панель пишет «проект не под git» и не даёт коммитить.
- В демо-режиме (без локального сервера) панель скрыта.
- Подпись автора берётся из `KAITOS_GIT_NAME` и `KAITOS_GIT_EMAIL`, по умолчанию `Kaitos <kaitos@localhost>`.
