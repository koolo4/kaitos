# Проверка проекта

## Как запускать

```bash
npm test          # все наборы: jsdom + node
npm run test:live # против запущенного сервера
npm run build     # сборка
```

## Что важно

- Зависимости ставятся автоматически перед тестами.
- Итог прогона печатается в конце: имена проваленных наборов.
- Наборы не должны зависеть от платформы: никаких ls и grep внутри тестов.
