# План разработки Kaitos — 12 задач для JustAI

Kaitos — AI-редактор кода в браузере (аналог Cursor / Claude Code). Первая фаза: **каркас приложения**.
Каждый файл `NN-*.md` — готовое тело задачи: цель, нумерованные требования, полный текст файлов,
критерии «Готово, когда» и «Не делать». Исполнитель — локальная модель ~8B, поэтому все файлы даны целиком.

## Как создать задачи

```bash
gh auth status                 # нужен доступ к koolo4/kaitos с правом Issues: write
python3 plan/create_issues.py --dry-run
python3 plan/create_issues.py
```

Скрипт создаёт задачи по порядку, ставит метку `justai` и проставляет `Depends on #N` реальными номерами.
Повторный запуск ничего не дублирует.

## Проверка

После каждой задачи: отчёт в issue («Проверки проекта», «Изменения в ветке», PR) и сценарий `/justai e2e #N`.
Слияние — `/justai merge #N`, когда проверки зелёные и сценарий PASS. Сценарии из `tests/e2e/` прогоняются
перед каждым слиянием, поэтому задачи 11–12 закрепляют проверки постоянно.
