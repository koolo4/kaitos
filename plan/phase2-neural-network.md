# Фаза 2 — нейросеть и инструменты агента

Каркас (фаза 1) готов: экран, дерево файлов, редактор, чат, терминал, настройки, палитра команд.
Эта фаза делает из каркаса настоящий AI-редактор: модель отвечает на вопросы о коде и умеет его менять.

> **Статус:** пункты 1–4 сделаны (см. `docs/ARCHITECTURE.md`): `js/llm.js`, `js/prompts.js`,
> `js/chat.js` с потоковыми ответами и `js/markdown.js`. Пункты 5–8 остаются планом.

Задачи ниже — заготовки для JustAI. Ставить их в GitHub issues нужно после слияния PR #35,
иначе новый код обгонит каркас. Каждая задача — один-два файла, файлы даются целиком.

## Что важно решить до старта

1. **Провайдер.** Ollama на ПК1 (локально, без интернета) или OpenAI-совместимый API по ключу.
   В настройках уже есть выбор провайдера, имени модели, адреса API и ключа — задача 1 читает эти поля.
2. **CORS и адрес.** Из браузера запрос к `http://localhost:11434` требует включённого CORS в Ollama
   (`OLLAMA_ORIGINS=*`). Для внешних API ключ нельзя держать в браузере на публичном сайте — нужен
   локальный прокси (задача 8) или провайдер, разрешающий браузерные запросы.
3. **Проверка модели.** Сценарная проверка (`/justai e2e`) не должна требовать сети: в задачах 1–7
   используем подмену ответа в тестах (`window.Kaitos.llm.setMock(...)`), живой запрос проверяем вручную.

## Как проверять каждую задачу

- `/justai e2e #N` со сценарием из описания задачи: сценарий подменяет сеть заглушкой и проверяет
  отрисовку ответа, кнопки, состояния ошибок.
- Постоянные сценарии — в `tests/e2e/`, они прогоняются перед слиянием.
- Живой запрос к модели — отдельным issue `/justai run #N node tests/manual-llm.js` на ПК1,
  где Ollama уже запущена.
