Цель: Добавить постоянные сценарии проверки интерфейса: каркас экрана и рабочая область (редактор, чат, терминал). Они прогоняются перед каждым слиянием.

Проект: Kaitos — AI-редактор кода в браузере (аналог Cursor / Claude Code).
Стек: Vite 5 + ванильный JavaScript, ES-модули. Все файлы — в корне репозитория.
Файл `index.html` уже существует, его менять нельзя: в нём зафиксированы id элементов.

Требования:

1. Формат файлов — YAML, шаги соответствуют движку `/justai e2e`.
2. Создай файл `tests/e2e/shell.yml` с текстом ниже — инструментом write_file. Пиши весь текст целиком, ничего не сокращая, не пересказывая и не добавляя от себя.

````
name: Каркас экрана
steps:

  - expectVisible: '#sidebar'
  - expectVisible: '#editor-panel'
  - expectVisible: '#chat'
  - expectVisible: '#terminal'
  - expectVisible: '#statusbar'
  - expectText: { selector: '#project-name', contains: 'demo' }
  - screenshot: { name: shell, width: 1280 }
  - click: '#btn-theme'
  - eval: { code: "document.documentElement.dataset.theme", expect: 'light' }
  - click: '#btn-theme'
  - eval: { code: "document.documentElement.dataset.theme", expect: 'dark' }
  - click: '#btn-settings'
  - expectVisible: '#settings-modal'
  - click: '#settings-close'
  - expectHidden: '#settings-modal'
  - click: '#btn-sidebar-toggle'
  - expectClass: { selector: '#app', has: sidebar-collapsed }
  - click: '#btn-sidebar-toggle'
  - expectVisible: '#sidebar'
  - screenshot: { name: shell, width: 375 }
  - expectNoConsoleErrors:
````

3. Создай файл `tests/e2e/workspace.yml` с текстом ниже — инструментом write_file. Пиши весь текст целиком, ничего не сокращая, не пересказывая и не добавляя от себя.

````
name: Редактор, чат и терминал
steps:
  - click: '.tree-row[data-path="src/utils.js"]'

  - expectCount: { selector: '.tab', equals: 1 }
  - expectCount: { selector: '.tab.is-active', equals: 1 }
  - eval: { code: "document.querySelector('#editor-input').value.includes('export function greet')", expect: true }

  - screenshot: { name: editor, width: 1280 }

  - click: '#chat-send'
  - wait: 1200
  - expectCount: { selector: '.chat-msg', min: 3 }
  - expectCount: { selector: '.chat-msg--user', min: 1 }
  - screenshot: { name: chat, width: 1280 }
  - type: { selector: '#terminal-input', text: 'ls' }

  - type: { selector: '#terminal-input', text: 'cat docs/notes.md' }
  - press: Enter
  - expectText: { selector: '#terminal-output', contains: 'Заметки' }
  - click: '#btn-terminal-toggle'
  - expectClass: { selector: '#main-area', has: is-terminal-collapsed }
  - click: '#btn-terminal-toggle'
  - expectVisible: '#terminal-output'
  - screenshot: { name: editor, width: 375 }
  - expectNoConsoleErrors:
````
