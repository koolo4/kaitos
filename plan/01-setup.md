Цель: Подготовить npm-проект с Vite, чтобы ПК1 мог установить зависимости и запустить приложение. Кода приложения в этой задаче ещё нет — только конфигурация.

Проект: Kaitos — AI-редактор кода в браузере (аналог Cursor / Claude Code).
Стек: Vite 5 + ванильный JavaScript, ES-модули. Все файлы — в корне репозитория.
Разметка приложения живёт в index.html, стили — в css/, код — в js/. Какие файлы создать или заменить, сказано в требованиях.

Требования:

1. Создай в корне репозитория четыре файла — ниже они идут по порядку.
2. Создай файл `package.json` с текстом ниже — инструментом write_file. Пиши весь текст целиком, ничего не сокращая, не пересказывая и не добавляя от себя.

````
{
  "name": "kaitos",
  "private": true,
  "version": "0.1.0",
  "type": "module",
  "description": "Kaitos — AI-редактор кода в браузере",
  "scripts": {
    "dev": "vite --port 5173 --strictPort",
    "build": "vite build",
    "preview": "vite preview --port 5173 --strictPort"
  },
  "devDependencies": {
    "vite": "^5.4.10"
  }
}
````

3. Создай файл `justai.app.json` с текстом ниже — инструментом write_file. Пиши весь текст целиком, ничего не сокращая, не пересказывая и не добавляя от себя.

````
{
  "install": "npm install",
  "start": "npm run dev",
  "url": "http://localhost:5173",
  "readyTimeoutSec": 120
}
````

4. Создай файл `.gitignore` с текстом ниже — инструментом write_file. Пиши весь текст целиком, ничего не сокращая, не пересказывая и не добавляя от себя.

````
node_modules/
dist/
.DS_Store
*.log
````

5. Замени всё содержимое файла `README.md` на текст ниже — инструментом write_file (не edit_file). Пиши весь текст целиком, ничего не сокращая, не пересказывая и не добавляя от себя.

````
# Kaitos

AI-редактор кода в браузере — аналог Cursor / Claude Code: дерево файлов, редактор с вкладками,
чат с ассистентом, встроенный терминал, палитра команд и настройки модели.

## Запуск

```bash
npm install
npm run dev
```

Приложение откроется на http://localhost:5173

## Стек

- Vite 5 (сборка и dev-сервер), без фреймворков
- Чистый ES-модульный JavaScript (`js/*.js`)
- CSS-переменные, тёмная и светлая темы (`css/style.css`)

## Структура

```
index.html          разметка всего экрана (панели, вкладки, чат, терминал, модалки)
css/style.css       дизайн-система и вёрстка
js/app.js           точка входа: собирает модули, связывает их между собой
js/dom.js           помощники для DOM
js/fs.js            виртуальная файловая система (демо-проект в памяти)
js/editor.js        редактор кода: вкладки, нумерация строк, сохранение
js/tree.js          дерево файлов в левой панели
js/chat.js          панель ассистента (пока демо-ответы)
js/terminal.js      встроенный терминал (виртуальные команды)
js/settings.js      настройки: провайдер, модель, ключ, тема, шрифт
js/palette.js       палитра команд (Ctrl+K)
tests/e2e/*.yml     постоянные сценарии проверки интерфейса
```

## Дорожная карта

1. **Каркас** (сейчас): экран, дерево файлов, редактор, чат, терминал, настройки, палитра.
2. **Нейросеть**: подключение Ollama и OpenAI-совместимых API, потоковые ответы.
3. **Инструменты агента**: чтение/запись файлов, правки diff-ом, команды терминала.
4. **Локальный сервер**: доступ к настоящим файлам на диске, git-панель.
````

6. Убедись, что файлы лежат именно в корне репозитория, а не в подпапке: пути — `package.json`, `justai.app.json`, `.gitignore`, `README.md`.

Готово, когда:
- В ветке появились четыре файла с указанным содержимым.
- Команда `/justai run #N npm install` (подставь номер этой задачи) завершается с кодом 0 и создаёт папку node_modules.
- `npm run dev` запускает Vite без ошибок конфигурации (страница пока отдаёт 404 — это ожидаемо, index.html появится в задаче 2).

Не делать:
- Не создавай index.html, папки css/ и js/ — это следующие задачи.
- Не меняй настройки репозитория и не трогай другие файлы.
